# 🆕 Day 91 – Remove Duplicates from Sorted Array

## 📌 Problem Information

- **Problem Number:** 26
- **Problem Name:** Remove Duplicates from Sorted Array
- **Platform:** LeetCode
- **Difficulty:** Easy
- **Programming Language:** Java
- **Topic:** Arrays and Two Pointers
- **Directory:** `Day-91`
- **Solution File:** `Remove Duplicates from Sorted Array.java`
- **Screenshot:** `Screenshot 2026-10-25 071105.png`
- **Status:** ✅ Completed

## 🎯 Problem Description

Given an integer array `nums` sorted in non-decreasing order, remove duplicate elements in-place so that each unique element appears only once.

The relative order of the unique elements must remain unchanged.

Return `k`, the number of unique elements in the array. The first `k` elements of `nums` must contain the unique values in sorted order.

The elements beyond index `k - 1` can be ignored.

The solution must modify the original array without creating another array.

## 💡 Approach: Two Pointers

This solution uses the **Two Pointers** technique to remove duplicates efficiently while preserving the order of unique elements.

Two variables are used:

- **`i` — Traversal Pointer:** Checks each element in the sorted array.
- **`k` — Unique Element Pointer:** Tracks the next position where a unique element should be placed.

Because the array is sorted, duplicate elements appear next to each other. We compare the current element with the last unique element to determine whether it should be added to the unique portion of the array.

## 💻 Java Solution

    class Solution {
        public int removeDuplicates(int[] nums) {
            int k = 1;

            for (int i = 1; i < nums.length; i++) {
                if (nums[i] != nums[k - 1]) {
                    nums[k] = nums[i];
                    k++;
                }
            }

            return k;
        }
    }

## ⚙️ Algorithm

1. Initialise `k = 1` because the first element is always unique for a non-empty array.
2. Traverse the array from index `1` to the last index using `i`.
3. Compare `nums[i]` with `nums[k - 1]`.
4. If both values are different, the current element is unique.
5. Store the unique element at `nums[k]`.
6. Increment `k` to track the next available position.
7. Continue until all elements have been checked.
8. Return `k`, the total number of unique elements.

## 🧪 Example 1

**Input:**

`nums = [1, 1, 2]`

**Output:**

`k = 2`

**Modified Array:**

`[1, 2, _]`

**Explanation:**

The duplicate occurrence of `1` is ignored. The first two positions contain the unique elements `1` and `2`.

The function returns `2` because there are two unique elements.

## 🧪 Example 2

**Input:**

`nums = [0, 0, 1, 1, 1, 2, 2, 3, 3, 4]`

**Output:**

`k = 5`

**Modified Array:**

`[0, 1, 2, 3, 4, _, _, _, _, _]`

**Explanation:**

The algorithm retains the first occurrence of each distinct value and places the unique elements in the first five positions.

The resulting unique portion is `[0, 1, 2, 3, 4]`.

The remaining positions can contain any values because the judge checks only the first `k` elements.

## 🔍 How the Solution Works

### 1. Initialise the Unique Element Counter

`int k = 1;`

The array is guaranteed to contain at least one element. Therefore, the first element is already part of the unique portion.

### 2. Traverse the Array

`for (int i = 1; i < nums.length; i++)`

The loop begins at index `1` because the first element has already been considered.

### 3. Check for Duplicates

`if (nums[i] != nums[k - 1])`

This condition compares the current element with the last unique element.

If the values are equal, the current element is a duplicate and can be skipped.

If the values are different, the current element is unique and must be retained.

### 4. Place the Unique Element

`nums[k] = nums[i];`

The unique value is copied into the next available position in the original array.

### 5. Update the Counter

`k++;`

The unique element count increases by one, and `k` moves to the next available position.

### 6. Return the Result

`return k;`

The function returns the number of unique elements in the modified array.

## ⏱️ Complexity Analysis

Let `n` represent the length of the input array.

- **Time Complexity:** `O(n)` — Each element is examined at most once.
- **Auxiliary Space Complexity:** `O(1)` — The algorithm uses only a constant amount of additional space.

The solution is efficient because it modifies the original array directly without allocating another array.

## 🎓 Learning Outcome

This problem strengthened my understanding of the Two Pointers technique and demonstrated how a sorted array can be modified efficiently without additional memory.

It also reinforced the importance of maintaining the relative order of unique elements and returning the correct number of valid elements.

**Key Takeaway:** Two pointers can efficiently remove duplicates from a sorted array in-place with `O(n)` time and `O(1)` auxiliary space.

# 🆕 Day 90 – Merge K Sorted Lists

## 📌 Problem Information

- **Problem Name:** Merge K Sorted Lists
- **Platform:** LeetCode
- **Programming Language:** Java
- **Topic:** Linked Lists and Priority Queue
- **Directory:** `Day-90`
- **Solution File:** `Merge k Sorted Lists.java`
- **Screenshot:** `Screenshot 2026-10-24 164503.png`
- **Status:** ✅ Completed

## 🎯 Problem Overview

Given an array of `k` linked lists, where each linked list is sorted in ascending order, merge all the linked lists into one sorted linked list and return it.

## 🧪 Example

**Input:**

`lists = [[1,4,5],[1,3,4],[2,6]]`

**Output:**

`[1,1,2,3,4,4,5,6]`

The given linked lists are:

- `1 → 4 → 5`
- `1 → 3 → 4`
- `2 → 6`

After merging all the lists, the resulting linked list is:

`1 → 1 → 2 → 3 → 4 → 4 → 5 → 6`

## 💡 Approach: Priority Queue

The solution uses a Priority Queue (Min-Heap) to efficiently select the smallest available node from the linked lists.

### Algorithm

1. Insert the first node of each non-empty linked list into the Priority Queue.
2. Create a dummy node to initialise the merged linked list.
3. Remove the node with the smallest value from the Priority Queue.
4. Attach that node to the merged linked list.
5. Insert the selected node's next node into the Priority Queue, if one exists.
6. Repeat until the Priority Queue is empty.
7. Return the merged linked list starting from `dummy.next`.

## 🧠 Concepts Practised

- Singly Linked Lists
- Priority Queue
- Min-Heap
- Dummy Node Technique
- Efficient Merging
- Time and Space Complexity Analysis

## ⏱️ Complexity Analysis

Let `N` represent the total number of nodes across all linked lists, and `k` represent the number of linked lists.

- **Time Complexity:** `O(N log k)`
- **Auxiliary Space Complexity:** `O(k)`

The Priority Queue contains at most one node from each linked list at a time, making the approach efficient for merging multiple sorted lists.

## 🎓 Learning Outcome

This challenge improved my understanding of linked list manipulation and the use of a Priority Queue to efficiently select the smallest available element.

It also reinforced how appropriate data structures can improve algorithm efficiency.
