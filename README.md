## 🆕 Day 97 – Longest Valid Parentheses

### 📌 Problem Information

- 📅 **Day:** 97
- 💻 **Problem:** Longest Valid Parentheses
- 🔗 **LeetCode Problem:** 32
- 🎯 **Difficulty:** Hard
- ☕ **Programming Language:** Java
- 🧠 **Approach:** Stack
- 📚 **Topics:** String, Dynamic Programming, Stack
- 📁 **Directory:** Day-97
- 📄 **Java File:** Longest Valid Parentheses.java
- 📸 **Screenshot:** Screenshot 2026-10-31 155741.png
- ✅ **Status:** Completed

### 🎯 Problem Statement

Given a string containing only the characters '(' and ')', return the length of the longest valid (well-formed) parentheses substring.

The objective is to identify the longest continuous substring in which every opening parenthesis has a matching closing parenthesis in the correct order.

### 📝 Example 1

**Input:**

    s = "(()"

**Output:**

    2

**Explanation:**

The longest valid parentheses substring is "()".

### 📝 Example 2

**Input:**

    s = ")()())"

**Output:**

    4

**Explanation:**

The longest valid parentheses substring is "()()".

### 📝 Example 3

**Input:**

    s = ""

**Output:**

    0

**Explanation:**

An empty string contains no valid parentheses substring.

### 💡 Approach: Stack

I solved this problem using a Stack to track the indexes of parentheses.

**Algorithm:**

1. Create a stack to store the indexes of parentheses.
2. Initially, push -1 into the stack as a base index.
3. Traverse the string from left to right.
4. If the current character is '(', push its index into the stack.
5. If the current character is ')', pop the top element.
6. If the stack becomes empty, push the current index as the new base index.
7. Otherwise, calculate the valid substring length using the current index minus the top index of the stack.
8. Update the maximum length using Math.max().
9. Return the maximum valid parentheses length.

### 🔍 Java Solution

The complete Java implementation is available in:

`Day-97/Longest Valid Parentheses.java`

### ⚙️ Complexity Analysis

| Complexity | Value | Explanation |
|---|---|---|
| Time Complexity | O(n) | Each character is processed once. |
| Space Complexity | O(n) | Stack stores character indexes. |

**Key Takeaway:** Stack is an effective data structure for solving parentheses matching and valid substring problems.
